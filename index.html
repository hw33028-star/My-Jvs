GitHub workflow: Train → Save (downloads a .zip folder containing corpus.txt + model.json) → unzip → commit model.json to your repo → enable Pages → paste https://USER.github.io/REPO/model.json above → Load URL.
Continue training: Load a model, then click Train again — it picks up from where it left off. Any new words in the textarea are appended to the vocab (existing word IDs never shift), so old knowledge is preserved.
jsDelivr works too: https://cdn.jsdelivr.net/gh/USER/REPO@main/model.json (great for repos that also host this HTML).
Why it works: GitHub Pages & jsDelivr both send Access-Control-Allow-Origin: *, so fetch() succeeds inside Google Sites' iframe.
